# 🚀 ML 2 Project

Welcome to the **ML 2 Project** repository! This is a central hub for advanced Machine Learning, Deep Learning, and Artificial Intelligence applications, featuring modern UI/UX design and professional-grade models.

## 🎥 Project Showcase: Thinking Style Analyzer

An AI-powered application that analyzes text using Natural Language Processing to determine cognitive thinking styles. It categorizes your thinking into Logical, Creative, Analytical, and Emotional patterns with a beautiful glassmorphism interface.

## 🛠 Getting Started

To explore a project, simply navigate into its directory and follow the instructions in its specific `README.md`.

For example, to run the **Thinking Style Analyzer**:
```bash
cd thinking-style-analyzer
pip install -r requirements.txt
python app.py
```
Open **http://127.0.0.1:5000** in your browser.
